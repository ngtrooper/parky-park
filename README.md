# Spot Thief
Race rival drivers for the best parking spot. Your little white wedge car has thrusters: launch off the ramp, boost, fly, flip and steal the farthest spot before anyone else. LAUNCH mode has endless procedural lots, a seeded Daily Lot, coins and a shop; PUZZLE mode has 8 handmade levels.

Play: https://ngtrooper.github.io/parky-park/

- ◀ ▶ drive / air-steer · SHIFT/B boost · ▲/W/SPACE thrusters · S/↓ hop · Q/E spin & flip · R instant retry · Enter run again/next · Esc menu
- `node tools/launch_tune.mjs` shows which spots an autopilot reaches at each upgrade tier.
- `npm run dev` to play locally, `node tools/solve.mjs` proves every level is 3-star beatable in the real sim,
  `node tools/browser_test.mjs` replays those solutions in headless Chromium.

Parody game. Not affiliated with any car or rocket company.
